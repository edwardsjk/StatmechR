# StatmechR: Integrating statistical and mechanistic modeling for epidemic prediction

## Introduction

The `StatmechR` package is a collection of functions designed to facilitate the integration of statistical and mechanistic modeling to improve early epidemic predictions.  
The framework contained within the `StatmechR` package uses these two modeling techniques in an iterative "coupled" fashion to leverage their strengths.  
Below we will provide instructions on downloading the `StatmechR` package and introduce the vignettes offered. 

## Installation

Please install and load the `StatmechR` package using the following code:

```R
devtools::install_github("edwardsjk/StatmechR", ref = "abby")
library(StatmechR)
```
R may require you to provide an authentication token for installation. To include your github token use the argument `auth_token = "your_token"`.
